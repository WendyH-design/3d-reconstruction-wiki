# 3D 重建基礎與多視角幾何概念（Foundations of 3D Reconstruction）

本頁面介紹多視角 3D 重建與新視角合成（Novel View Synthesis, NVS）的核心基礎概念，為理解後續神經輻射場（NeRF）與 3D Gaussian Splatting（3DGS）奠定幾何觀念基礎。

---

## 1. 核心任務：從 2D 照片到 3D 空間

在傳統攝影中，一張數位相機拍攝的照片本質上是一個 **2D 像素陣列**（以寬度與高度為軸的離散 RGB 數值）。而相機拍照的過程是一個 **降維投影**：現實世界中的 3D 物體經過透鏡折射後，被投影至 2D 感光元件上，導致**沿著視線方向的深度（Depth）資訊完全遺失**。

### 1.1 核心任務分流：3D 幾何重建 vs. 新視角合成（NVS）
在當代電腦視覺中，主要區分兩種技術目標與產出形式不同的任務：
1. **3D 幾何重建（3D Geometric Reconstruction）**：
   - 核心目標：精準復原物體在 3D 空間中的真實幾何形狀與空間坐標位置。
   - 輸出形式：稠密點雲（Point Clouds）、三角網格（Meshes）或體素網格（Voxel Grids）。
2. **新視角合成（Novel View Synthesis, NVS）**：
   - 核心目標：給定一組已知視角的輸入照片，演算法合成並生成「從未被拍攝過的全新視角觀察點」下的 2D 照片 [Mildenhall et al., 2020, Sec 1](../evidence/mildenhall2020-nerf.md#2-研究問題與核心技術貢獻)。
   - **關鍵認知**：**新視角合成的直接產出是「照片的逼真呈現」，其渲染過程中不必然保證產出拓撲結構水密、形狀完全精確的 3D 表面網格**。這是評估 3D 重建品質時最常見的認知陷阱。

### 1.2 新視角合成的兩大表徵範式：隱式神經場 vs. 顯式高斯點集
在新視角合成的發展脈絡中，存在兩種根本不同的場景表徵哲學：
1. **隱式連續輻射場（Implicit Neural Radiance Fields）**：
   - 代表方法：[NeRF (Mildenhall et al., 2020)](nerf.md)。
   - 表徵機制：使用多層感知機（MLP）神經網絡權重，隱式記憶場景中連續三維空間每一點的體積密度與視角相關顏色。渲染時沿著光線步進採樣，計算成本高但表徵解析度無上限。
2. **顯式 3D 高斯表徵（Explicit 3D Gaussians）**：
   - 代表方法：[3D Gaussian Splatting (Kerbl et al., 2023)](3dgs.md)。
   - 表徵機制：使用數十萬至數百萬個具備三維位置、協方差矩陣、透明度與球諧顏色的顯式高斯橢球點集表徵場景。結合分塊（Tile-based）排序與 GPU 光柵化，實現即時（100+ FPS）高解析度渲染 [Kerbl et al., 2023, Table 1](../evidence/kerbl2023-3dgs.md#62-table-1-評估數據保持原生解析度ours-30ksec-72-table-1-p-8)。

## 2. 為什麼需要多角度照片？視差與三角測量

單張照片因為深度資訊遺失，在幾何上存在無限多種可能的外觀尺度與空間位置排列（尺度與深度歧義性）。

為了找回遺失的深度，必須依循人類雙眼立體視覺的原理，從**兩個或兩個以上的不同視角**觀察同一個物體：

```
       [ 物體表面空間點 P(X, Y, Z) ]
                /          \
               /            \
              / (視線光線 1)   \ (視線光線 2)
             /                \
    [相機 1 光心 o1]        [相機 2 光心 o2]
        (照片 1)                 (照片 2)
```

1. **視差（Disparity）**：同一個物體表面特徵點，在不同位置拍攝的照片中，其像素坐標會發生位移。離相機越近的物體，視差位移量越大；離相機越遠的物體，位移量越小。
2. **三角測量（Triangulation）**：若已知兩台相機在空間中的相對位置與朝向（相機姿態），並從兩張相片中識別出同一個物理特徵點，兩條視線光線在空間中交會的一點，即為該物體特徵點的真實 3D 坐標 $(X, Y, Z)$。

## 3. 相機光線（Camera Ray）數學表示

在以射線步進為核心的神經輻射場（NeRF）等新視角合成技術中，相機觀察場景的基本幾何載體是 **相機光線（Camera Ray）** [Mildenhall et al., 2020, Sec 4, p. 409](../evidence/mildenhall2020-nerf.md#32-體積渲染機制連續積分與離散數值求積sec-4-p-409410)：

$$\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$$

- $\mathbf{o} \in \mathbb{R}^3$：相機的光心位置（Camera Origin / Center of Projection）。
- $\mathbf{d} \in \mathbb{R}^3$：光線穿過 2D 像素平面的 3D 單位方向向量（Viewing Direction）。
- $t \in [t_n, t_f]$：光線前進距離，以近平面 $t_n$ 與遠平面 $t_f$ 為邊界。

沿著這條光線步進採樣，便可評估空間中不同位置的物體密度與發光顏色。

## 4. 關鍵概念釐清：SfM 技術概念 vs. COLMAP 軟體工具

在進行 3D 重建或訓練 NeRF / 3DGS 之前，必須先知道「每張照片是在空間中的哪個位置、朝哪個方向拍攝的」（相機外參矩陣）。

初學者常將 SfM 與 COLMAP 混為一談，此處必須精確區隔：

### 4.1 運動恢復結構（Structure-from-Motion, SfM）
- **本質**：一種**電腦視覺演算法框架與技術概念**。
- **功能**：透過一組無序拍攝的照片，自動比對特徵點（如 SIFT 特徵），在「相機姿態未知」的前提下，同時估算出每張相機的 3D 位置與旋轉角度（相機外參），以及場景中特徵點的稀疏 3D 點雲。

### 4.2 COLMAP
- **本質**：當前學術界與產業界最廣泛使用的**開源 SfM / MVS 軟體工具**（由 Johannes Schönberger 等人開發）。
- **在 3D 重建中的角色**：
  - 在 NeRF 論文中，作者對真實世界拍攝的照片，均是使用 **COLMAP 工具** 來自動估算每張照片的相機姿態與深度範圍 [Mildenhall et al., 2020, Sec 5.3, p. 413](../evidence/mildenhall2020-nerf.md#41-測試資料集與場景細節sec-61-p-413414)。
  - 在 3DGS 論文中，作者同樣使用 COLMAP 估算的相機姿態以及生成的稀疏點雲，作為 3D 高斯橢球初始化的起點 [Kerbl et al., 2023, Sec 4, p. 4](../evidence/kerbl2023-3dgs.md#22-三大核心創新貢獻-sec-1-p-2)。
  - **重要限制**：COLMAP 是實現 SfM 的一種具體工具；若拍攝環境缺乏紋理或光線劇烈變化，COLMAP 可能發生特徵配對失敗或相機姿態漂移。
